# ADR-0023: Mobile-first dan tetap nyaman di laptop

- Status: diterima; rincian terbuka dicatat di bawah.
- Tanggal: 2026-09-05.
- Stage utama: [00](../stages/00-keputusan-desain.md).

## Konteks

Keputusan frontend 3: pengguna memilih mobile-first secara eksplisit.

## Keputusan

Utamakan layout dan interaksi layar HP; aplikasi tetap nyaman digunakan pada laptop/desktop.

## Konsekuensi

Form bertumpuk, teks membungkus, tombol mudah disentuh, dan tidak bergantung pada hover. Kartu pada gambar desktop perlu diadaptasi. Jangan memaksakan tabel lebar pada input harian mobile.
