# ADR-0024: Light mode dan dark mode

- Status: diterima; rincian terbuka dicatat di bawah.
- Tanggal: 2026-09-05.
- Stage utama: [00](../stages/00-keputusan-desain.md).

## Konteks

Keputusan frontend 4: pengguna memilih B.

## Keputusan

Sediakan light mode dan dark mode. Kedua tema merupakan cakupan awal UI, bukan fitur tambahan di akhir.

## Konsekuensi

Gunakan token warna konsisten dan periksa kontras, focus, error, disabled, serta komponen upload pada kedua tema. Default mengikuti sistem dan penyimpanan preferensi belum ditetapkan sebagai keputusan pengguna.
