# ADR-0020: Validasi lokal terlebih dahulu

- Status: diterima; rincian terbuka dicatat di bawah.
- Tanggal: 2026-09-05.
- Stage utama: [08](../stages/08-verifikasi-lokal.md).

## Konteks

Keputusan bisnis 20: menerima rekomendasi C.

## Keputusan

Jalankan aplikasi secara lokal untuk validasi awal. Lokasi deployment untuk pemakaian tim diputuskan kemudian.

## Konsekuensi

Sediakan petunjuk menjalankan aplikasi serta backup/restore SQLite dan attachment. Setup VPS, domain, CI/CD deployment, dan server instansi belum diminta.
