# ADR-0017: Definisi indikator task nyangkut

- Status: diterima; rincian terbuka dicatat di bawah.
- Tanggal: 2026-09-05.
- Stage utama: [06](../stages/06-dashboard.md).

## Konteks

Keputusan bisnis 17: pengguna menyetujui usulan.

## Keputusan

Task nyangkut adalah task open tanpa realisasi selama 5 hari kerja. Jika belum pernah direalisasikan, hitung dari tanggal dibuat. Adanya rencana baru tidak membatalkan indikator.

## Konsekuensi

Realisasi dihitung lintas user pada task yang sama; ini indikator aktivitas task, bukan penugasan permanen. Kalender dan batas hitung harus konsisten dengan ADR-0006 dan Q-01.
