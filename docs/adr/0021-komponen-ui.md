# ADR-0021: shadcn-vue dan Tailwind CSS

- Status: diterima; rincian terbuka dicatat di bawah.
- Tanggal: 2026-09-05.
- Stage utama: [00](../stages/00-keputusan-desain.md).

## Konteks

Keputusan frontend 1: menerima rekomendasi A.

## Keputusan

Gunakan shadcn-vue + Tailwind CSS sebagai dasar komponen dan styling frontend Vue.

## Konsekuensi

Gunakan komponen yang diperlukan oleh fitur dan aksesibilitasnya; hindari menambah library UI kedua tanpa kebutuhan nyata. Ini pilihan komponen, bukan pergantian framework frontend.
